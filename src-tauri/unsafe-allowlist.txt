# Files allowed to carry `#![allow(unsafe_code)]`.
#
# Workspace lint is `unsafe_code = "deny"` (`src-tauri/Cargo.toml`). The
# only escape hatch is a per-file `#![allow(unsafe_code)]`. Every file
# listed below has been reviewed and the inner `unsafe` blocks are
# justified inline with `// SAFETY:` comments.
#
# Adding a new entry to this list is a load-bearing decision — require an
# explicit PR with a documented justification. The
# `scripts/check-unsafe-allowlist.sh` prek hook fails any commit that
# introduces a `#![allow(unsafe_code)]` outside this allowlist.
#
# Paths are relative to `src-tauri/`. Comments (lines starting with `#`)
# and blank lines are ignored.

# Android WiFi multicast lock: JNI FFI into `WifiManager` is the only way to
# acquire it. Moved out of the app crate with the rest of the sync cluster in
# #2621 Sync-D; the stale `src/sync_daemon/…` entry this replaces had made the
# file invisible to the hook, which only walked `src-tauri/src/` until #3847
# widened it to every workspace member.
agaric-sync/src/sync_daemon/android_multicast.rs

# #3852: Android per-uid network-block reporting. JNI FFI is the only way to
# reach `ConnectivityManager.registerDefaultNetworkCallback`, whose
# `onBlockedStatusChanged` is the platform's authoritative statement about this
# uid's firewall status — the only non-inferential source for the block that
# makes a first-ever pair impossible on Android 15+. Same two `unsafe` blocks
# and the same invariant as `android_multicast.rs`; the pure reporting rule
# (`blocked_transition`) carries no `unsafe` at all.
agaric-sync/src/sync_daemon/android_network_block.rs

# #3847: installs the process-global Android `JavaVM` + Application `Context`
# from `JNI_OnLoad` (`ndk_context::initialize_android_context` and
# `JavaVM::from_raw` are both `unsafe`). Without it the first sync task to ask
# `ndk_context` for the context aborted the process.
agaric-sync/src/android_context.rs

# #3847: the exported `JNI_OnLoad` symbol itself. Must be defined in the crate
# that produces the `cdylib` to be exported reliably; `#[unsafe(no_mangle)]` is
# what trips the lint here.
src/android_jni.rs

# #2720: Windows named-pipe security descriptor. The `#[cfg(windows)]`
# `win_security` module uses inline Win32 FFI (advapi32/kernel32) to build a
# per-user DACL so the MCP pipe is not squattable/readable by other local
# users. Each unsafe block is justified inline with `// SAFETY:`.
src/mcp/mod.rs
