# Every tool, toolchain and download the build fetches from outside the repo,
# in one place (AGENTS.md § Supply-chain pinning). Workflows, composite
# actions and the setup scripts read this file through scripts/pins.sh; the
# lockfiles, Actions SHAs, the Gradle verification file and the file pins
# (`FILE_PINS` in scripts/pins.mjs: `.nvmrc`, `rust-toolchain.toml`,
# package.json's `packageManager`, `.mcp.json`) pin the rest.
#
#   version <name> <version> <upstream>
#   asset   <name> <platform> <sha256> <url>    `{version}` expands to the version
#
# Bump with `just pin-bump <name> <version>`: it rewrites the version and
# recomputes every asset's sha256. `just pins-stale` lists pins behind their
# upstream (weekly in scheduled-deep-checks). Upstreams:
#   taiki:<tool>     the manifest of the taiki-e/install-action SHA CI uses
#                    (CI installs it from there, checksummed)
#   github:<repo>[@<tag-prefix>]   newest GitHub release
#   crate:<name>     newest stable version on crates.io
#   lock:<crate>     the version of <crate> in src-tauri/Cargo.lock
#   temurin:<major>  newest Temurin JDK release of that major
#   android-emulator newest stable-channel emulator build
#   android-sdk:<pkg>;<major>   newest stable <pkg> release of that major
#   tauri-bundler:<tool>   the name tauri-bundler's prepare_tools fetches at the
#                    Tauri CLI tag package-lock.json resolves; any difference
#                    is stale
#   rust-nightly     today's nightly; flagged once the pin is 28 days old
# Every pin names an upstream (scripts/pins.test.mjs). Left floating on
# purpose: runner images, apt and brew packages; the Android platform and
# emulator system image, which follow the app's target and test SDK levels
# (`platforms;android-<N>`, `api-level`), not a release line; and the Gradle
# files `cargo tauri android init` generates.
# Platforms: linux-x86_64 linux-aarch64 darwin-x86_64 darwin-arm64 windows-x86_64
