# Session 1555 — widen the B6 op-chain generator (#4679)

Closes #4679. The generator behind the reconciliation oracle (B6, `apply_reproject_proptest.rs`) could not reach four of #3345's remaining artefacts: every `SetProperty` carried `value_date: None`, so its `due_date` op was a payload the command layer rejects and the apply path projected as `UPDATE blocks SET due_date = NULL`; `scheduled_date` was not a key; B6 filtered every tag op and seeded no tag block; and both drivers stamped `blocks.space_id` themselves, so an oracle over it would have diffed the test's own constant against a rebuild rooted in the same constant.

The harness now routes the `SetProperty` payload by key: the reserved date keys carry a calendar-valid `YYYY-MM-DD` in `value_date`, `space` carries a `value_ref` into one of two harness-owned space ids, everything else stays `value_text`; a harness test drives every generated `SetProperty` through `validate_property_value`. `prepare_chain_b5` (B5 and B6) re-targets `SetProperty(space)` onto the rooting page, so the chain migrates the whole page group between the two spaces; B2–B4 keep `prepare_chain`, which drops it because they read one fixed engine. A space op is only emitted while nothing is soft-deleted, since production hydrates live rows only and a later restore would take the SQL-only fallback the suites forbid. The seeded tag is `date/2025-01-15`, the shape `agenda_cache`'s tag arm selects, and stays a leaf (#4789). Both drivers stamp only `parent_id`/`page_id`; `resolve_block_space` resolves through the owning page, and B6 fills `space_id` through `settle_block_space_ids_for_op`, which asks production's `invalidations_for_op` and runs the maintainer it names. The B1 inverse-law oracle compared `value_text` only, which with date and ref payloads would be `None == None`, so it now compares the typed triple.

`OracleCoverage` gains `date_column_rows`, `block_tag_edges` and `distinct_block_spaces`, asserted non-zero on a chain that could drive each. Left out: oracles for the new artefacts (#3345), `#[ULID]` tag-ref injection, recurrence properties. A production gap surfaced on the way and is #4801: `hydrate_page_subtree_into_engine` seeds from `block_properties` only, so a page moved to another space loses its reserved-column dates in the new doc.
