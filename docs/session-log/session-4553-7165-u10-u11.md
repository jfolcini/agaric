**U10, phone Trash**

- Edited old assertion: `phone-view-headers.spec.ts` "Trash: one title, its actions kept…" expected `trash-empty-trash-btn` visible; it now expects the ⋮. **U11, references header**

- The header line is the `CollapsiblePanelHeader` alone: the source-page filter and the "N filters" badge go. The badge's i18n keys stay, since `UnlinkedReferences` still uses them.
- `BacklinkFilterBuilder` gains `afterAddFilter`, rendered inside `FilterBar`'s existing `addFilter` slot right after the button, so the order is Add filter, Source pages, Clear all, sort. `SourcePageFilter`'s trigger is an outline `size="xs"` button (Add filter's size) labelled "Source pages", or "Source pages · N" with N picked pages included or excluded, with no icon. Its accessible name is its visible label now, not "Filter by source page", which stays as the phone sheet's title. Picked states keep their colours; the idle state takes the outline default, as Add filter does, not the old muted icon colour.
- The kind toggle's `coarse:mt-2` goes. It kept the segments' 44 px targets, 4 px above their 36 px frame, clear of the header filter's own 4 px overhang. The header toggle has no overhang, so `mt-1` leaves them touching, not overlapping. The toggle sits 4 px higher on touch.
- On a phone the extra button wraps the sort control onto a row of its own, as `FilterBar` lays out trailing controls that do not fit.
- `filter-bar-layout.spec.ts`, desktop and phone: "References: Source pages follows Add filter; the header line holds only its toggle" checks the actions row's direct buttons are `['Add filter', 'Source pages']`, the button has no icon and Add filter's height, only one button sits on the header's line, and picking a page reads "Source pages · 1". Red before the fix on both profiles: no Source pages in the actions row.
