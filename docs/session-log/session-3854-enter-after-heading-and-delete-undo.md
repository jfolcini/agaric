# Session 3854 — Enter after a heading starts a plain block; the block menu's Delete offers Undo

Issue #6547 asked for three block-mode fixes. Two landed here; the Escape one did not (see below).

**Enter at the end of a heading or quote.** `splitAtCaret` (`src/editor/use-roving-editor.ts`) serialised `doc.cut(from)` as the tail, and at the very end that is an empty heading or quote, `# ` / `> `, so `handleEnterSave` took its split branch and created a heading. It now returns `after: ''` when the caret is at `Selection.atEnd(doc).from`, and the existing empty-tail branch creates a plain sibling. A text comparison would have been wrong: a tail holding only a chip has no text but must split (the existing "before an inline atom" test reds on that mutation). A mid-heading split still gives two headings. Page mode and the Markdown buffer already followed the rule.

**The block menu's Delete.** `SortableBlock`'s swipe-delete callback became `deleteWithUndo(id)`, and the bag the row hands its `BlockContextMenu` swaps `onDelete` for it, so the menu's Delete raises the same "Block deleted · Undo" toast backed by `undoDeleteOf`. The menu component itself is untouched because page mode and the source toolbar mount it with their own delete. Backspace on an empty block stays silent. The trash button a partial swipe reveals (`SwipeAffordances`) is the same swipe delete and was silent; it now takes `deleteWithUndo` too.

**Not done, blocked on existing tests** (the brief forbids editing them):
- The batch bar's Delete getting an Undo action: `use-block-multi-select.test.ts` pins `toast.success` called with exactly `('blockTree.deletedMessageUndo')`, so a second `opts` argument reds it.
- Escape's batch bar from two blocks only, and the task checkbox kept in selection mode: e2e specs `block-select-cursor`, `escape-keeps-text`, `block-paste-outline` (and the one-block cases in `batch-operations` / `block-keyboard-select`) assert the bar with one block selected, and `BlockInlineControls.test.tsx` pins the task checkbox hidden in selection mode.
