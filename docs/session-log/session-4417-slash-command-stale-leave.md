# Session 4417 — a content slash command's text reaches the editor before its write

**Ask.** Root-cause `page-mode-slash.spec.ts` "/callout-warning", which once stored block mode's block as `buy milk ` with no callout, in a loaded bridge run.

**Cause.** `applyContentEdit` committed the editor's pending text, wrote the command's text, and only then put that text into the editor. Until then the editor still showed the text from before the command, so a leave in that window (the spec's Escape) wrote it. The block was then mid-write, so that write went without a base, and the real backend, which runs two edits of a block on two writer connections, could commit it after the command's: the callout was erased. A traced bridge run had the command's pending commit go first, the leave's write next, then the callout, with the leave's landing last.

**Change.** The editor and the store take the command's text before its write goes out, so a leave or a keystroke while it is on its way builds on it; the pending commit then has nothing older to write and the call that flushed it goes. A refused write puts back what the block showed and saves it through the store's `edit`. The editor is no longer remounted when the write answers, which could re-open a block the user had left. Every content slash and Turn-into command shares this path.

**Shown.** `page-mode-slash.spec.ts` gains "a leave while block mode's /callout-warning is writing keeps the callout": the command's pending commit answers only once the block is left, and a write started while another is on its way lands after the command's, as concurrent writes can on the real backend. On the bridge it fails 3 of 3 with main's `applyContentEdit` (the block holds `buy milk `) and passes 5 of 5 with the change. In `useSlashCommandStructural.test.ts` the #6935 case now pins that the command's text is in the editor and the store when its write goes out; a new case that a keystroke while the write is on its way builds on the command's text and is not remounted away when it answers; and another that a refused write puts back the shown text and saves it. Each is red with its part of the change undone: the early mount, the dropped remount, the revert, the save.
