# Session 4196 — A page's outgoing links; a count on a referenced block and a touch peek

Built #6749 and both boxes of #6746 as PR B of a batch whose PR A is #6751 (#6799).

**Outgoing links (#6749).** A collapsed *Outgoing links* section after the reference sections of `PageEditor`, grouped by target page with *Unresolved* last, each row naming and jumping to the linking block, with Linked references' kind toggle (`KindToggle`, now exported). It reads nothing until opened, through a new cursor-paginated `list_outgoing_links` command. The issue's premise that one read over `block_links` suffices was false: a purged target, or one in another space when the source was indexed, has its row in `block_links_unresolved`, so the read unions both and classifies the unresolved table's rows by the source text, as migration 0119 classified `block_links`. A link whose target is purged after the link was written is in neither table and is not listed; the docs say so. The journal week and month day views carry no unlinked references either, so the section stays out of them.

**Reference count (#6746, box 1).** The existing `count_backlinks_batch` caps at 1000 ids, which cannot keep "one count call whatever its size", so a page-scoped `count_backlinks_in_page` returns only the blocks with a count, every link kind, live sources of the space. `useBlockRefCounts` serves a `BlockTree` through context; the count follows property chips' visibility (always in block mode, on the pointed or focused block in page mode). Activating it zooms the block; page mode has no zoom, so it switches the page to block mode first, a view change that is not saved.

**Touch peek (#6746, box 2).** On a touch phone a long press on a `((ref))` chip opens the peek's content as a bottom sheet with *Open* and *Copy reference*; a tap still navigates, and inside the block being edited the long press stays the system's text selection.

**Tests.** Rust tests for both commands and their conformance handlers, a backend-authored `query_outgoing_links` fixture pinning the mock; vitest with `axe` and rejection paths for the new components; `e2e/outgoing-links.spec.ts` and `e2e/block-ref-count.spec.ts`. Each was shown red first or falsified by one mutation. `e2e/perf.spec.ts`'s page-open and link-click IPC lists gain the one count call.
