# Session 3389 — Footnotes, numbered by first appearance (#6033 S11)

Set out to build #6033 S11 to the design the maintainer approved on the issue (2026-11-04), with their one change: references are renumbered 1, 2, 3 by the order their labels first appear on the page, while the stored text keeps the label.

**What shipped (TS only).** `[^label]` is an inline `footnoteRef` atom (parser `scanFootnoteRef`, serializer, `RichContentRenderer`, `revealed-markers`), in `contentExtensions` so block mode and page mode both have it. A block starting `[^label]: ` defines it. `src/editor/footnotes.ts` builds one label → number map per page from the page store's blocks in tree order, cached on the blocks array (a WeakMap), so the numbering is built once and recomputed only when the page's blocks change; `useRichContent` subscribes only for blocks whose text holds `[^`, which a Profiler test pins. A defined reference is a followable superscript (click, Enter or Space focuses its definition through `onNavigate`); an undefined one is muted with a tooltip. Typing `[^label]` converts on the closing `]` through a `handleTextInput` plugin so one Ctrl+Z brings the typed text back. The serializer writes `[^1]\(x)` when a `(` follows a reference so it cannot become a link, and a literal `\[^1\]` stays text.

**Decisions.** Only references count as appearances; a definition nothing refers to shows its label. Block mode's editor numbers from saved text, so a reference just typed shows its label until the block is left; page mode renumbers live. A label may not hold `[` or `\` (review: a later `]` could pair with it and turn the reference into a link at 20 000 property runs).

**Review fixes.** The static reference took no 44 px tap area and the browser's outline; it now has `touch-hit-area` and `focus-ring-visible`. Added pins for the selector guard, Space, spoken text (a reference reads as nothing), page mode's live numbering and click, and the phone tap area.

**Not done here.** The design's Rust checks (an import PCT holding references and an FTS test that `[^1]: text` is found by `text`) were left out of this TS-only slice; reading `strip_for_fts_with_maps`, the words pass through unchanged. Copying a reference and pasting it inside the editor degrades it to its label text, as page-link chips already do.

**Tests.** Parse, serialize and numbering units, node-view and typing tests in both modes, an axe-checked renderer test, round-trip seeds and a footnote property (20 000 runs after the label fix), and `e2e/footnotes-6033.spec.ts` (typed reference and definition, click focuses the definition, re-queried after navigating away and back; page mode; phone tap). Gates: full vitest (24527 passed), typecheck, lint, all and manual-stage hooks, and 1064 Playwright `@editor|@markdown|@journal` tests (`e2e-related` selects the whole lane because of `index.css`).
