# Session 2825 — page mode's remote patch gets the tests its mutation run asked for

Two test gaps the #5691 review of 2026-10-21 found in `remote-patch.ts`, which patches a peer's changes into page mode's document. `remote-patch.ts` itself is unchanged.

- **Repeated characters.** `remote-patch.test.ts` had no case where the old and new text share repeated characters, so only the property test noticed its two repairs both removed. A new table of cases (`aaa`→`aa`, `aa`→`aaa`, `abab`→`ab`, `xyyz`→`xyz`, `**aa**a`→`**a**a`) asserts the document and that the cursor stays put. Without the overlap trim the text still comes out right, because the fallback repairs it, so the cursor assertion is what goes red. The fallback is reachable: it fires when the diff starts inside a table cell and ends past the table, and two table cases now turn red without it.
- **Mutation enrolment.** `stryker.modules.mjs` enrols `remote-patch` with its unit test only (the property test stays out, as for `page-mode-fit`). Under this box's load the default timeouts reported most mutants as Timeout and hid survivors, so the run used `--timeoutMS 30000 --timeoutFactor 5`. That exposed 27 survivors over 263 mutants. About twenty new tests kill the ones that change behaviour: a sibling-gap insert, a move to the front, a peer's delete ending undo history, an unsaved local edit surviving another block's remote edit, the cursor after a moved block, refused-create ids, and patch positions mapped after an earlier delete. The rest are in `mutation-accepted.tsv` with their reasons: type-mandated defaults, conditions redundant by an invariant (unique ids, equal start and end nulls), and writes with no observable effect. The review reproduced all 25 the builder had accepted and found two wrong: saving a peer-inserted block without its text, and overwriting every saved block on a patch, both drop the hold that keeps a split block's text when its new half is refused. Two tests now kill them and their entries are gone, leaving 23.

The full run was not repeated after the last two tests, which were shown red by direct mutation. A whole-module run takes about thirty minutes at these timeouts.

Suites run: vitest on `remote-patch` and the page-mode property test, the Stryker module and runner tests, `check-stryker-modules`, typecheck, lint and oxfmt.
