# Session 3822 — the mirror's read-back setting, and #6504's review notes

#5363 slice 4, setting 1, with #6506 and the two review notes from #6504.

- **Reading changes back** is a device-local `app_settings` key, `mirror.read_back`, chosen with the folder (`set_mirror_folder` takes it, stored before the folder so the first tick already follows it) and changed with `set_mirror_read_back`. Off, `Mirror::ingest` answers `None`: a changed file stays diverged and is never written over, new files and renames are not read, and a vanished file is written again after the hold.
- **Turning it on again (decided 2026-11-11, relayed by the coordinator):** nothing is read in silently. `read_back::pending` lists each page file that is not its newest shadow or is gone, and each unowned `.md` in a space folder. It fails closed when the folder, its marker or the state files cannot be read. The status carries the list for the Data tab's dialog, and the command derives it again and refuses a plain turn-on while it is not empty. `AppError` has no payload slot, so the list is not in the error. No held set survives a restart, because the setting does not change until the user chooses.
- **#6506:** an empty page's file re-saved blank (a final newline or a BOM) was refused as an emptied save, and the page stopped mirroring. A page with no blocks has nothing to lose, so such a file is written back as the empty render, as an ingest writes back LF and no BOM. #6505's round trip now re-saves empty files too.
- **Review notes from #6504:** `ingest::rename` returns its refusal as a `String`, so the unreachable `NoBase` arm is gone. A refused rename used to leave the page in `missing`; when the hold ran out its old file was written again, two files for one page. The page now stays held while the refused file is as it was, and a second rename is read as that rename.
- **Traps:** the disk filled three times. Each time, split-debuginfo `.dwo` files in `target/debug/deps` (about 13 GB) and `target/debug/incremental` were the space to reclaim. A `gen-sqlx` run that hits ENOSPC deletes the caches it was rewriting; rerunning restores them.
- **Tests:** Rust tests in `ingest_tests.rs` and a proptest (whatever an outside tool does while it is off, no op is appended and no file it wrote is written over), each mutation-killed. Vitest for the switch and dialog, with `axe` and a rejection path. The Playwright spec ran against the installed Chromium through a scratch config (the pinned headless shell is not installed here). The spec `e2e-tauri/mirror-read-back.e2e.ts` could not run here; CI's real-backend lane is its first run.
