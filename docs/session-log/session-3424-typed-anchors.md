# Session 3424 — Typed `[[Page#Heading]]` anchors store a block ref (#6033 S10)

Set out to build #6033 S10. Typing `[[Page#Heading]]` or `[[Page#^ULID]]` linked the page and dropped the anchor, while import already resolved the same text to the block.

**What shipped.** `src/editor/anchor-block.ts` mirrors Rust's `anchor_block` / `obsidian_heading_text` / `normalize_heading_anchor`: a `^ULID` matches by id, a heading by the first line's ATX text, trimmed, white space collapsed and lowercased. `block-link-picker.ts` takes a `findAnchor` option (wired through `use-roving-editor.ts`, `BlockTree.tsx` and `PageModeEditor.tsx`) and, on `]]` or on picking the page in the popup, stores `((ULID))`; `![[Page#…]]` typed alone in its block (S5a's `embedsAt`) stores `{{embed ((ULID))}}`. `[[#Heading]]` looks on the editor's own page. An anchor that names no block links the page as before; a `|label` on a resolved anchor is dropped, since `((ULID))` has none.

**Conformance.** A hand-written `headingAnchors` section in `conformance/reference-tokens.vectors.json` (no `CONFORMANCE_UPDATE` writer exists for that file) is asserted by vitest and by the Rust test `heading_anchor_vectors_pin_which_block_an_anchor_names` against the real functions, so Rust judges every row. One known gap: Rust's candidate query prefilters with SQLite `ltrim(content) LIKE '#%'`, which strips only ASCII spaces, so a first line opening with a tab or NBSP before `#` is a heading to the editor and not to import; such text renders as a paragraph and cannot be typed into a block.

**Tests.** `anchor-block.test.ts`, `typed-anchor.test.ts` (block and page mode, typed and picked), the conformance describe, and `e2e/typed-anchor-links-6033.spec.ts` (four specs, including `[[#Heading]]` on its own page, each re-checked after navigating away and back). Reds shown: a stub resolver, exact-match headings, no lowercasing, and the own-page fallback removed. Gates: editor, components and lib vitest, typecheck, lint, all hooks, 79 related Playwright tests, the vectors nextest and clippy.
