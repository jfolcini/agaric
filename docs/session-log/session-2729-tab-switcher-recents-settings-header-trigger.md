# Session 2729 — tab switcher caret, no recents strip on Settings, header trigger alignment

Three items from a maintainer report (#5993).

**"Breadcrumbs" on Settings.** No header breadcrumb exists; the namespace breadcrumb in `PageHeader` only shows on a page and its last crumb is already plain text. The row of page chips under the tab bar (`QuickAccessBar`, the recents strip) was the one thing on Settings that opens a page, so it now renders nothing while `currentView === 'settings'`. Read narrowly: Settings only; the strip stays on Journal, Pages and the rest, where it is the phone's page switcher (#927). The other reading, that clicking the active tab from Settings should not return to its page, was not taken: the tab is the documented way back.

**Tab switcher.** The caret on the active tab and the click-the-active-tab-to-open behaviour are gone. One `IconButton` caret sits left of the tablist (outside it, so the tablist holds only tabs) and opens `TabSwitcher`, a cmdk `Command` in a Popover: filter input with focus on open, case-insensitive substring over the shown label and the full path, `shouldFilter={false}`, arrows and Enter from cmdk, Escape and focus return from Radix. The row close is an `aria-hidden` span, as on the strip, because a focusable widget inside `role="option"` fails axe's nested-interactive rule even at `tabIndex=-1`; keyboard close stays on the strip (Delete / Backspace, Ctrl+W). The switcher owns its open state, so it resets when the bar unmounts at one tab, which removed the old dropdown's ref-pruning and reopen guards.

**Sidebar trigger.** `self-start sm:self-center` pinned the 28 px mouse trigger to the top of the 48 px header below `sm`. `self-start` is only needed on touch, where the header's padding makes the first row the whole header unless it stacks, so it is now `self-center` plus `pointer:coarse:self-start`. On a stacked mouse header the trigger centres with the back/forward buttons.

Ran: `TabBar` and `QuickAccessBar` vitest, `npm run typecheck`, oxlint, oxfmt, and Playwright `tab-switcher`, `recent-pages-strip`, `app-chrome`, `menus-popovers` plus what `just e2e-related` selected. Each new test was shown red by breaking the code it covers.
