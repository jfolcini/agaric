# Session 3402 — Foreign highlight and math are stored in Agaric's form (#6033 S4, #6277 C4)

Set out to build #6033 S4 (= #6277 C4). Logseq's `^^x^^`, LaTeX's `\(x\)` / `\[x\]` and GitHub's ```` ```math ```` fence imported, pasted and saved as literal text, and the editor's parser decoded `\(` and `\[` as escaped punctuation, so the first edit lost the backslashes.

**What shipped.** A pure `normalize_foreign_inline` in `agaric-engine/src/import.rs` rewrites `^^x^^` → `==x==`, `\(x\)` → `$x$`, a `\[x\]` whose text holds a LaTeX command → a `$$` block (whole content) or `$x$`, and a ```` ```math ```` fence → a `$$` block. It runs at three choke points: `parse_import_payload` (import), `resolve_pasted_names` (paste, HTML block paste and every MCP content write) and `resolve_buffer_names` (Edit as Markdown, rows the save writes only). It skips code spans (CommonMark run-length pairing), fences and `$$` blocks (also inside quotes and callouts), escaped forms and `[[…]]` labels. The editor's serializer escapes a pairing `^^` run so Agaric's own text pastes back unchanged, and S1's one-line paste routing (`needsBlockPath`) also routes a line holding these forms.

**Data integrity.** The Q3 promise (Agaric's own text passes through unchanged) was attacked with throwaway harnesses: about 240 000 editor-serialized strings across text, rich and quoted shapes changed nothing once three accepted gaps were excluded (`^^` or `\(` inside inline-math LaTeX, a link's address or an image's alt, none realistic), plus 15 million multibyte and exhaustive strings with no panic. Review found and fixed one blocking case: code inside a quote or callout (`> ```sh`) was rewritten.

**Trades.** A `^^` pair stored before the escape existed reads as Logseq highlight and converts on its next paste or Edit as Markdown save; an earlier `\(x\)` that was edited already lost its backslashes. One existing test generator changed: `INTERESTING_CHARS` in `markdown-roundtrip.property.test.ts` gained `^`.

**Tests.** A Rust unit table, three proptests (own text unchanged, idempotent, no panic), PCTs for import and paste, an Edit as Markdown case, an MCP `append_markdown` case, serializer and routing vitest, round-trip seeds and `e2e-tauri/paste-foreign-syntax.e2e.ts` (CI). Gates: filtered nextest (1217), clippy, `cargo-doc-links`, editor and lib vitest, typecheck, lint, all and manual-stage hooks and 314 Playwright tests; re-verified after merging main.
