# Session 3591 — the page copy and the agent read share the writer

#6277 E4: one writer behind Export as Markdown, Copy blocks, the buffer, the mirror's file and the MCP page read, told apart by two policies.

- **`RenderMode` is two policies** (`markdown_export.rs`). `Names`: `Always` (every id that resolves, ref-typed values as titles) or `ReadBack` (only a name that reads back as the same id, values raw). `Anchors`: `Addressed` (what something addresses, plus what needs one), `Needed` (only a block that leaves a fence open or would read back as other content) or `Every`. Callers: Export as Markdown and the ZIP `Always`/`Addressed`; the mirror's file `ReadBack`/`Addressed`; Copy blocks `ReadBack`/`Needed`; the buffer, Duplicate, template copies and the MCP read `ReadBack`/`Every` (`RenderMode::DOCUMENT`). `push_export_bullet` and `push_buffer_bullet` became one `push_bullet`; the `Agent` mode, `render_page_for_agent(_spans)`, `render_page_head` and `file_anchors` are gone. A first block opening with `# ` is a `+` item under `Anchors::Addressed`, the file forms an import reads with its title rules. Attachment lines follow the data: only an export's read loads them.
- **The export's unaddressed blocks take the clipboard's "needed" test** (`push_clipboard_bullet`) instead of the fence-only one, so a block whose text alone would read back as other content (one ending in ` ^` and an id) gets its anchor there too. No export, conformance or e2e expectation changed.
- **MCP `get_page_markdown` returns one form**: `{ page_id, title, markdown, truncated, next_cursor }`, `markdown` being the page's buffer (front matter, no title line, names where they read back, every `^ULID`), still a `RESPONSE_BYTES_CAP` stretch at a time; read in turn, the stretches are the base `edit_page_markdown` takes. `editable` is gone (an agent still sending it is refused by `deny_unknown_fields`). `get_page_for_agent_inner` takes the cursor and returns `AgentPage`; the paged and unpaged variants are one. `get_journal` returns the day's buffer.
- **Gap 1 of the agent-access doc closes for reads**: a link into another space reads back as nothing in the agent's space, so the read writes its id, not its title. `gap_markdown_names_a_linked_page_of_another_space_5667` became `markdown_writes_a_linked_page_of_another_space_by_its_id_6277`.
- **A paste drops the front matter it opens with** (second commit). `import::read_pasted_text` finds the fence with `front_matter_fence`, as the buffer reads one, leaves its lines blank so each block keeps its line number, and adds one warning; a `---` anywhere else, or one no `---` line closes, is text. Paste and `append_markdown` both read through it, so a page copy pastes as one `# Title` heading and its blocks, and an agent's read appends as its blocks. The TS mirror is `readPastedText` (`source-buffer-document.ts`), which shares `frontMatterLength` with `blockText`; the mock's `paste_blocks` now returns that reader's warnings.
