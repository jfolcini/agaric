# Session 1546 — The set-state-in-effect rule is an error

Sixth PR of the batch run alongside a second agent in another container (1541 to 1545 carry the others). It closes #4407 in the scope the maintainer narrowed on 2026-09-02: review every `react(set-state-in-effect)` site, fix only where the state is a `useState` initializer or derivable during render, suppress the rest with a one-line reason, then promote the rule to error; the per-site "should this effect exist" redesign and the directory-by-directory PR series were dropped there.

Eighty-five sites across sixty-three files, swept by four builders in parallel and judged by one reviewer. Seven became initializers: three media hooks (`useIsMobile`, `useIsTouch`, `usePrefersReducedMotion`) carried a post-mount re-sync justified by a hydration mismatch the client-only app cannot have, `useScreenWakeLock` computed its unsupported flag one render late, the palette's recent-commands list arrived on a second frame, and the two IntersectionObserver-absent fallbacks (`AttachmentRenderer`, `DaySection`) sat behind a ref guard that, without an observer and before the placeholder mounted, gated the day forever. The remaining seventy-eight sites are data fetches, identity-change resets of state the user also writes, browser-API syncs and one-shot store handoffs; each carries a directive of at most twenty-five words naming the external thing it synchronises. The rule moves to error globally and the backlinks-only override goes with it.

Review reconciled the two fallback sites, which two builders had treated differently, into one shape, rewrote one reason whose field count was untrue, and cut two comments that narrated the deleted effects. The seven sites hidden under React Compiler bailouts (#4493) were enumerated by lint-ing unmasked copies: all seven are the same suppressible shapes, but a directive under a bailout reports as unused, so they stay masked and are listed in the PR.

Verified: each of the seven initializer fixes red with the derivation broken against a copy, restored `cmp`-identical; `npm run lint` with unused directives as errors exit 0 with zero `set-state-in-effect` and zero unused directives; full vitest 808 files, 18606 passed, 1 expected fail, 37 skipped; typecheck, knip and oxfmt clean.
