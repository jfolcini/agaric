# Session 3850 — One pass over the guard estate: slow hooks to CI, dead guards out

Issue #6566, all four checkboxes, in the issue's order. The hook count goes from 117 to 107 and `HOOK_CAP` equals it, so a new hook now has to replace one or raise the cap in a reviewed diff.

## What changed

- **Slow hooks to the `manual` stage.** The issue's four (`unanchored-content-regex`, `import-cycles`, `doc-vs-code-paths`, `metric-provable`) measured 3.5, 2.5, 1.8 and 1.8 s of user CPU here. Timing every whole-tree guard a TypeScript-only commit fires found three more well over 500 ms on every run (`check-set-property-args` about 1.9 s, `json-parse-cast` about 1.35 s, `lib-layering` 0.7 to 1.0 s), so they moved too: the issue's done-when is "no hook above 500 ms", not "these four". Three sit at the threshold within noise on a loaded box (`strict-invoke-optout`, `remove-after-markers`, `architecture-citations`, 0.4 to 0.8 s) and stayed.
- **Trap:** `docs-lint` named `doc-vs-code-paths` in a default-stage `prek run`, and prek drops a named `manual` hook from that run without a word. It now has its own `--hook-stage manual` step. That step's `run:` must stay one line: `check-remove-after-markers.mjs --self-test` reads the docs-lint job's single-line `run: prek run --all-files …`.
- **Trust-boundary guard deleted** (script, both hooks, the six `pr-overlap.yml` comments and the pointers in two other scripts). Shown once, not committed: switching `pr-overlap.yml` to `pull_request_target` makes zizmor 1.28.0 report `error[dangerous-triggers]` and exit 14. The overlap lane itself is untouched.
- **`axe-presence` widened, not deleted.** It now scans all 430 `*.test.tsx` under `src/components/` and `src/editor/`. The issue's "a directory passes if any test beside it audits" rule would have hidden every catch the guard has on record (each was a new file in a directory whose siblings audit), so the scan stays per file, and the 66 files with neither an audit nor an exemption are listed in `scripts/axe-presence-baseline.txt`, shrink-only. The builder brief forbids editing existing tests, so the baseline replaced 66 test edits. The baseline is declared in `check-baseline-paths.mjs` and routed to the frontend category in `classify-changes.sh` and `verify-ci-equivalent.sh`.
- **Version-pin trio deleted**, replaced by `scripts/check-tool-pins.mjs` (`tool-pins` hook), one short check over `setup-hooks.sh`, `zizmor-hook.sh` and every workflow `tool:` list. `check-tsgolint-version-pin.mjs` has no replacement: the `oxlint` hook runs `--type-aware`, so a missing tsgolint fails it loudly. The stale-but-in-range case its `VERIFIED_PAIRS` table caught is now unguarded.
- **`check-cache-poisoning-suppressions.mjs` deleted** with its references in `.github/AGENTS.md`, `ci.yml` and `zizmor.yml`.
- **Desk-check.** Deleted: `no-raw-invoke`, replaced by an oxlint `no-restricted-imports` entry (named and namespace `invoke` imports from `@tauri-apps/api/core`, `src/lib/ipc-helpers.ts` exempt; `check-baseline-paths` and its test moved off the deleted script), and `trace-interactions-named`, which `tsc` already enforces through the `InteractionName` parameter type. Kept, with the WHY line naming what nothing else catches: `check-set-property-args`, `persist-hooks`, `strict-invoke-optout`, `json-parse-cast`, `types-erasure`, `pairing-rejection-contract`, and `metric-provable`. `metric-provable` has no catch since its introduction but no other tool checks its defect class, and in the `manual` stage it no longer costs a commit.
