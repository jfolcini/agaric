# Session 3596 — `meeting_date` is a built-in Date

The first PR of #5364 slice 2 (S4 in the build plan on #5410). A meeting page carries `meeting_date`, so "meetings in October" is a date range in Advanced Query.

- The issue asked for a seed migration like 0103. Since #5841, built-ins are code constants and 0128 deleted the seeded rows, so this is one `BuiltinPropertyDef::of("meeting_date", "date")` entry plus its mirror in `src/lib/property-save-utils.ts`, with no migration. It is in neither `INTERNAL_PROPERTY_KEYS` (users see it) nor `SYSTEM_MANAGED_PROPERTY_KEYS` (users may remove it).
- The plan's builder check held: a space that defined `meeting_date` itself before this listed the key twice, its own `text` row and the built-in. `list_property_defs_inner` now sorts the built-in first within a key and drops the later duplicate. Declarations (`property_declaration`, the projection's value-type lookup) already read the built-in first.
- Red: the new `meeting_date_is_a_builtin_date_listed_once_over_a_users_row_5364` failed with `[("text", false)]` before the constant, and `[("text", false), ("date", true)]` with the constant but without the dedup; removing the dedup line again reddens it.
- agaric-reviewer caught that the UI hid every built-in from the add-property popovers (page table and block drawer), the sort picker and query columns, through `NON_DELETABLE_PROPERTIES`, so `meeting_date` could not be added by hand. Those four sites now read `APP_MANAGED_BUILTIN_KEYS`, every built-in but `meeting_date`; rename and key checks keep the full set. A test at each site went red before the fix, and red again with the set emptied.
- The backend-authored conformance fixtures and the `list_property_defs` MCP snapshot gain the `meeting_date` row. The regenerator re-sorted keys in some files, so each fixture carries only its one added line, and both sides of the conformance check pass on it.
- cargo-nextest could not be installed in this container, so the Rust runs used `cargo test` per test binary; the conformance fixtures were regenerated with that one test filtered alone.
