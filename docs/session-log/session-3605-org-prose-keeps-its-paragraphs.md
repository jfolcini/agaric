# Session 3605 — Org prose keeps its paragraphs (#6032 N5)

Built #6032 N5 on its own, ahead of #6277 E3 (maintainer): a Logseq or Org import (`LogseqOrg`, `parse_logseq_markdown`) keeps a block's interior blank lines, as the Document reader already did, so a bullet's paragraphs and an Org section's, which `org-import.ts` writes at its headline bullet's content column, no longer run together.

- `parse_block_lines` (`agaric-engine/src/import.rs`) holds every blank line in `blank_run`, not only a fence's on import; `append_continuation_line` writes the run before the next continuation line once the block has text: as written before code, as empty lines before prose. A leading blank line (a bare `-` bullet) and a trailing one (before the next block, a property line or the end) are still no block's, and a blank line before a dedent still ends the block. `ParseMode` and `Scan` are unchanged. A blank line before a fence-opening continuation line is now kept too; a blank line inside a fence was already.
- Planning, `key:: value` and `:LOGBOOK:` lines after a blank line read as before: they take no blank run, which the next line clears. `rewrite_org_blocks` runs on the stored content after the scan, and turns a kept blank line in a `#+BEGIN_QUOTE` into `>`, so the quote keeps its paragraphs too.
