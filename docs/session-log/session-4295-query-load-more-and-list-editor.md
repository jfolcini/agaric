# Session 4295 — an inline query's Load more and a query table's list editor survive the real backend

Two frontend bugs that kept `query-blocks.spec.ts` and `query-table-list-filter.spec.ts` off `REAL_BACKEND_SPECS` (#6529). Both files now join it.

- **#6911, Load more dropped.** The backend's late events for the query block's own save move a refresh counter while `fetchNextPage` is in flight. `useInvalidateOnCounter` invalidated at once, and `invalidateQueries` cancels a running fetch and refetches only the pages the cache holds, so the second page vanished. The fix waits for any Load more in flight under the prefix (`fetchMeta.fetchMore`, its `query.promise`) and invalidates once it lands, so the refetch covers every page. `cancelRefetch: false` was rejected: it joins the running fetch, and the success clears the invalidation, so a refresh would be lost. The fix sits in the shared hook, so every infinite list it refreshes (references, unlinked references) gets it.
- **#6912, list editor closing.** The cause is not the refetch. `ListEditor` disabled its add field while the write ran. Chromium moves focus off a field that becomes disabled at its next rendering update, and the query table's cell closes when its field loses focus to nothing. The mock answers before that update, so the field was enabled again in time. The bridge is slower, so focus moved and the cell closed. The add field is now `readOnly` while busy. The `writing` ref already refuses a second write. The Properties table's list editor shares the component and kept the same lost focus.

Each fix was shown red with the fix reverted: a vitest test (the hook test, with a held next page; the ListEditor test, with a held `set_property`), and on the bridge (Load more 3 of 6 failed at the post-click row assertion; the list cell failed 2 of 2 at `Remove Dee`).

Ran: typecheck, oxlint, vitest over `src/hooks`, `src/components/properties` and `src/components/query`; both files on the bridge (`--repeat-each=5`, 90 passed) and on the mock with the neighbouring query, references and property specs. `just e2e-related` names the whole lane for the hook, so CI's run is that check.
